# Portfolio delivery contract

- For a project milestone, update the case study, this repository's README, and the project's own README/status documentation together. Update homepage/library/index summaries when capabilities change.
- Keep evidence and scientific limitations aligned with the source repository. Distinguish local GUIs from hosted demos; do not imply institutional affiliation or validation without evidence.
- Test static links/navigation and visible light-background contrast. Run the existing validation scripts.
- Commit and push authorized changes through normal review, check CI, merge and verify GitHub Pages/live content. Report blockers rather than calling local changes published.
- Preserve unrelated user files and changes, including scratch profile documents. Do not publish private job descriptions, attachments, credentials or restricted inputs.
