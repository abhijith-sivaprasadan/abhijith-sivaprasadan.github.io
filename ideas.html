INDUSTRIAL DECARBONISATION

EnPI baseline-drift detector

An online add-on that flags when a baseline regression has lost predictive power, using a rolling KS-test or CUSUM on residuals. It closes the loop between metering, regression and audit-ready reporting.

METHOD STUDY

Insulation cost-benefit overlay on the Pulsatorn rig

Extend the thesis insulation case to a parameter sweep: blanket thickness 20 to 100 mm, k 0.05 to 0.15 W/mK, external h 2 to 10 W/m²K. The output is a Pareto front of cost against delivered-temperature loss.

REUSES → SIEMENS THESIS PHYSICS
CHT VALIDATION

Bartz against RANS calibration on a test bench

A small heated-channel rig, Re 10⁴ to 10⁵, heat flux up to about 50 kW/m², with embedded thermocouples and a precision power meter. Compare measured heat-transfer coefficients with Bartz-scaled predictions and k-omega SST results.

REUSES → SIEMENS THESIS CFD/CHT
OPEN SOURCE

Browser-side physics layer, extracted

This site's physics module already holds isentropic relations, 1-D thermal resistance circuits, Bartz scaling and ISO 50006 EnPI in one audited place. A standalone npm package or Python twin would let others reuse the same formulas.
