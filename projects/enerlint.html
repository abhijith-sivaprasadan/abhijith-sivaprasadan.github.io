Research question

Do exported physical quantities satisfy the mass and energy relationships the modeller declared, and where are conservation checks insufficient?

Implemented foundation

The v0.1.0a0 public alpha includes four hand-constructed analytical examples, a strict JSON/SI input contract, SHA-256 linked machine-readable reports, and negative-control/fault-injection tests.

Important negative result

Six deliberately inconsistent perturbations are detected; a compensating compressor error still passes the balance checks. A pass is not proof of the original model, input data, or physics.

Open Energy Methods

EnerLint is the first public research-stage tool in the Open Energy Methods initiative, with openly documented scientific scope, roadmap, adapter contract and verification methodology.

An independent result is not the same as an independent model

Where a conservation check earns trust—and where it cannot.

EnerLint is deliberately placed outside the modelling tool that generated the result. It reads exported quantities and checks declared physical identities, creating a separate evidence record. That separation is useful, but it does not independently reconstruct the original physical system or certify the solver.

01 · INPUTS A declared physical contract +

The alpha starts from an explicit JSON/SI contract. Inputs identify the quantities and declared tolerances being checked, while SHA-256-linked machine-readable reports make it possible to trace which export was examined.

Inspectable record: source, schemas and tests. A complete input contract is a prerequisite for a meaningful residual, not proof that the assumptions behind it are true.

02 · POSITIVE CONTROLS Analytical balance cases +

Four hand-constructed cases are used to exercise mass, energy and thermal-storage consistency relationships. These establish how the implemented checks behave on declared example quantities; they do not establish accuracy for all turbine, building or grid models.

Verification material: published benchmark record.

03 · NEGATIVE CONTROLS Six faults detected; one false pass +

Six deliberately inconsistent perturbations are flagged by the current balance tests. The more important adversarial case is a compensating compressor error: errors cancel at the balance level and the overall check passes despite an internally incorrect component interpretation.

Scientific implication: low residual magnitude is a useful test result, but it is not a certificate of local physical correctness. Explore the documented false pass.

04 · OPEN GATE What must be established next +

The alpha needs broader independent reference cases, adapter testing on real exported model structures, clearer observability of component-level errors and external scientific review before stronger model-verification claims are warranted.

Boundary: no industrial qualification, independent experimental validation, certification, public package release or safety-critical use is established. Compare the separate ThermoTwin-F educational simulation case for a different kind of verification problem.
