How every page here is read

Four terms, always in this order

  1. 01 · Boundary

    What is in scope

    The control volume is drawn first, so nobody has to guess what a result covers.

  2. 02 · Method

    How it was analysed

    Solver, model, data source or procedure, named plainly enough to be repeated.

  3. 03 · Evidence

    What was found

    Numbers with units and the check that supports them.

  4. 04 · Residual

    What is not claimed

    In CFD the residual is what is left when the solver stops. Here it is what is left when the claim stops.

Working style

Validate assumptions early

Prefer clear boundary conditions, documented limitations and sanity checks before scaling a model or a test setup.

Connect analysis to hardware

Keep instrumentation, test constraints and model interpretation tied together instead of treating simulation as a standalone exercise.

Move between disciplines

Switch between thermal-fluid engineering, energy systems and software implementation while keeping the same standard of evidence, traceability and technical communication.
